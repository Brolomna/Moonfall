# 🌕 Moonfall

같은 와이파이에서 즐기는 **웨어울프(늑대인간) 파티 게임** 웹앱입니다.
호스트는 휴대폰으로 게임을 진행하고, 플레이어는 각자 휴대폰으로 QR을 찍어 들어와 자기 역할 카드를 봅니다.
밤 행동·토론·투표는 실제로 모여서 하고, 앱은 카드 배분 · 밤/낮 전환 · 호스트 진행 가이드를 담당합니다.

## 시작하기

```bash
npm install
npm run dev
```

터미널에 나오는 주소로 접속하세요 (휴대폰과 컴퓨터가 같은 와이파이여야 합니다).

- 호스트: `http://<컴퓨터 IP>:5173/host`
- 플레이어: 호스트 화면의 QR 코드를 찍거나 `http://<컴퓨터 IP>:5173/`

게임 당일에는 빌드해서 하나의 서버로 실행하는 게 더 가볍습니다.

```bash
npm run build
npm start          # http://<컴퓨터 IP>:3000/host
```

> 맥에서 처음 실행하면 "들어오는 네트워크 연결 허용" 창이 뜰 수 있어요 → **허용**을 눌러야 휴대폰에서 접속됩니다.
> 글꼴은 Google Fonts에서 불러오므로 인터넷이 없으면 기본 글꼴로 보입니다.

## 들어 있는 것

**호스트 (3단계)**
1. 초대 — 실제 QR 코드, 플레이어 화면 기본 언어, 하우스 룰, 입장한 플레이어 목록(내보내기)
2. 역할 — 늑대인간/마을 사람/메이슨 개수, 특수 역할 선택, 밸런스 미터, 역할 직접 만들기·수정
3. 진행 — 밤/낮 전환(모든 폰 배경이 바뀜), 밤 깨우는 순서, 특수 상황 카드, 플레이어 표시(살해/추방/이탈), 도플갱어 처리, 승리 판정

**플레이어**
- 이름 입력 → 대기 → 카드(탭해서 뒤집기) — 게임 끝날 때까지 유지
- 살해/추방되면 전용 카드로 바뀜 · 게임 가이드 · 7개 언어

## 구조

| 경로 | 내용 |
|---|---|
| `server/index.ts` | Socket.IO 방 서버 (메모리 저장, 방 1개) |
| `src/views/` | 디자인 시안에서 변환된 화면 (HostView / PlayerView) |
| `src/HostApp.tsx`, `src/PlayerApp.tsx` | 서버 연결 |
| `design/` | 디자인 캔버스 원본 (`.dc.html`) |
| `tools/` | 시안 → React 변환(`dc2tsx.py`), 서버 연결 패치(`wire.py`) |

Claude Code에서 작업할 때 참고할 내용은 `CLAUDE.md`에 정리되어 있습니다.
